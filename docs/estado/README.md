# Documentos de estado

Aqui se guardan los resumenes de estado del data warehouse que se generan a pedido.

**Nombre de cada archivo:** `<solicitud>_AAAAMMDD_HHMMSS.md`, donde `<solicitud>` describe lo que se pidio (en minusculas, con guiones bajos) y la fecha y hora son las de generacion (hora local).

Ejemplo: `resumen_estado_actual_20260928_144917.md`.

Cada documento es una foto del momento en que se genero: no se actualiza despues. Para un estado nuevo se crea otro archivo.
